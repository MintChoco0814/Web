이렇게 해논 이유가 일반적으로 데이터 값을 받으면 
[
    {
    key: value, 
    }
]
이렇게 나오는데

위에 처럼 설정하면 내가 입력한 값이 

{
    "user_info": [
        {
            key:value,
        }
    ]
}
이런 식으로 설정이됨 
개인 정보 수집이나 아니면 따로 위치정보 수집할 때 처럼 
예를 들어 만든다면 
{
    "user_info":[
        {
            key:value
        }
    ]
    "user_location":[
        {
            key:value
        }
    ]
}
이런식으로 만들 수 있음
